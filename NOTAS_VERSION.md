# Extreme Fighters v0.5.1

> 🧪 Early development release. If you find a bug, open an issue and attach the `logs` folder.

## ✨ New
- 📦 **One download**: the room server now comes inside the installer. There's no separate `ExtremeFighters_Servidor.zip` anymore.
- 🌐 **Online → Open public server on this PC**: opens 6 public rooms while the game is open, opens your router by itself (UPnP) and shows the address to share. Others type it in *Public rooms → Server*.
- For rooms open 24/7 without the game, run `Iniciar_servidor.bat` from the `servidor` folder of your install.

## How to update
- **From v0.4.0 or newer**: open the game, press **Esc → Update to v0.5.1** (or use the **UPDATE** button in the installer).
- **From v0.3.0 or older**: run the new `Instalar.exe`, pick your `.3ds` and the **same install folder**.
